# backbeat

Home of **[Backbeat](backbeat/)**: an ad-free, offline metronome for Android, in the same
retro arcade-and-VCR style as Djungleskwidgets and Funhouse. Its clicks are placed to the
audio frame, so it keeps time however busy the phone is, and a pixel ball hops along the
beat lights to show each beat coming. Its Ear listens as you play along and scores every
hit against the click, arcade style, and can find the tempo of a song playing nearby. See
[`backbeat/README.md`](backbeat/README.md) for what it does, how to install it and how it
works.
